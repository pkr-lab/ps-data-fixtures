## Dateibenennungskonvention

Alle Dateien in diesem Bereich folgen der Standard-Konvention:

```
[Präfix]_[Suffix]_[Nummer].[Format]
```

**Verfügbare Präfixe:**
- Java
- Python
- Datenbanken
- Netzwerktechnik
- Zahlensysteme
- PowerShell

Siehe [NAMING_CONVENTION.md](../NAMING_CONVENTION.md) für die vollständige Liste der Suffixe pro Präfix.

## Best Practices

1. **Klar benennen** - Verwende aussagekräftige Suffixe
2. **Konsistent bleiben** - Behalte die Benennungskonvention bei
3. **Dokumentieren** - Füge kurze Beschreibungen hinzu
4. **Organisieren** - Nutze die Unterordner sinnvoll
5. **Teilen** - Stelle deine Ressourcen mit der Gruppe bereit
