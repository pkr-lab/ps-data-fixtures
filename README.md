# ps-data-fixtures

Testdaten für PowerShell-Skripte: eine künstliche SharePoint-Struktur für die IT-Ausbildung mit drei Jahrgängen und rund 750 Beispieldateien, benannt nach `[Kürzel]_[Präfix]_[Suffix]_[Nummer].[Format]`.

## Quickstart

```sh
git clone https://github.com/pkr-lab/ps-data-fixtures.git
```

Den Ordner `IT-Ausbildung/` als Quelle für Skripte wie DocFlowEngine verwenden.
